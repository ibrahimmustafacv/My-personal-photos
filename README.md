# Ibrahim Mustafa | Personal Portfolio 📸👨‍💻

هذا المشروع عبارة عن موقع شخصي (Portfolio) تفاعلي وعصري للمطور وصانع المحتوى **إبراهيم مصطفى**. يهدف الموقع إلى استعراض الصور الشخصية الخاصة بي، بالإضافة إلى مقاطع فيديو توثق لحظاتي الخاصة، بطريقة جذابة، احترافية، وسهلة التصفح.

## ✨ المميزات (Features)

* **تصميم عصري وداكن (Dark Theme):** مريح للعين ويعطي طابعاً أنيقاً يبرز جمال الصور الشخصية والفيديوهات.
* **شاشة تحميل تفاعلية (Loader):** شاشة انتظار أنيقة تظهر عند فتح الموقع.
* **معرض صور ديناميكي (Dynamic Gallery):** يتم تحميل الصور الشخصية برمجياً وعرضها بنظام شبكي (Grid).
* **نظام العرض التفاعلي للصور (Related & Zoom View):** عند النقر على أي صورة، تفتح شاشة منبثقة تعرض الصورة بشكل أكبر مع ظهور صور أخرى ذات صلة (Related Images) حولها بتأثيرات حركية (Animations) رائعة.
* **مشغل فيديو مخصص:** قسم خاص لعرض الفيديوهات الشخصية مع أزرار تحكم مخصصة (Play/Pause) مصممة بالـ CSS.
* **تجاوب كامل (Fully Responsive):** الموقع متوافق تماماً مع جميع الشاشات (أجهزة سطح المكتب، الأجهزة اللوحية، والهواتف الذكية).
* **تأثيرات التمرير (Scroll Animations):** ظهور العناصر تدريجياً (Fade Up) أثناء التمرير لأسفل الصفحة.

## 📁 هيكلة المجلدات والملفات المطلوبة (Folder Structure)

لكي يعمل الموقع برمجياً (حسب كود الـ JavaScript الموجود)، **يجب** أن يكون هيكل الملفات في جهازك أو خادمك مقسماً كالتالي:

```text
📁 Your-Project-Folder/
├── 📄 index.html                 # ملف الموقع الرئيسي (الكود الذي قمت بكتابته)
├── 🖼️ Conquest logo.png          # شعار الموقع المستخدم في شاشة التحميل
│
├── 📁 Picture/                   # مجلد الصور الشخصية الرئيسية
│   ├── A.jpg
│   ├── B.jpg
│   └── ... (وصولاً إلى Z.jpg)
│
├── 📁 Related/                   # مجلد الصور ذات الصلة (تظهر عند النقر على الصورة الرئيسية)
│   ├── 📁 A/
│   │   ├── A1.jpg
│   │   ├── A2.jpg
│   │   ├── A3.jpg
│   │   └── A4.jpg
│   └── 📁 B/ (وهكذا لبقية الحروف...)
│
└── 📁 One break/                 # مجلد الفيديوهات الشخصية
    ├── A.mp4
    └── B.mp4
```
*(ملاحظة: إذا لم تكن هذه المجلدات موجودة، سيقوم الموقع تلقائياً بعرض رسائل تنبيهية مكان الصور والفيديوهات توضح مسار الملف المفقود).*

## 🛠️ التقنيات المستخدمة (Technologies Used)

* **HTML5**: لبناء هيكل الموقع والأقسام.
* **CSS3**: لتنسيق الألوان، الخطوط، التجاوب مع الشاشات، وإضافة حركات الـ (Keyframes & Transitions).
* **Vanilla JavaScript**: 
  * التحكم في شاشة التحميل.
  * جلب الصور (A to Z) والصور ذات الصلة بشكل ديناميكي.
  * تشغيل/إيقاف الفيديوهات.
  * مراقبة التمرير (Intersection Observer) لتفعيل الـ Animations.
* **Font Awesome (v6.4.0)**: لاستخدام الأيقونات (أزرار التشغيل، الإغلاق، والسوشيال ميديا).

## 🚀 كيفية التشغيل (How to Run)

1. قم بإنشاء المجلدات المذكورة في قسم "هيكلة الملفات" (`Picture`, `Related`, `One break`) وضع صورك وفيديوهاتك الشخصية بداخلها بنفس الأسماء المطلوبة.
2. ضع ملف الشعار `Conquest logo.png` في المجلد الرئيسي.
3. قم بفتح ملف `index.html` في أي متصفح حديث (Google Chrome, Firefox, Safari).
   * **نصيحة للمطورين:** لتجنب مشاكل سياسة الـ (CORS) عند تحميل بعض الصور محلياً، يُفضل تشغيل المشروع باستخدام خادم محلي (مثل إضافة **Live Server** في برنامج VS Code).
